# summary

Get a search index.

# description

Gets an index by API name, display name, or ID.

# examples

- Get by name:
  <%= config.bin %> <%= command.id %> --target-org my-org --name Knowledge_Index
- Return JSON:
  <%= config.bin %> <%= command.id %> --target-org my-org --name Knowledge_Index --json

# flags.name.summary

Search index name or ID.
