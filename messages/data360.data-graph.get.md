# summary

Get a data graph.

# description

Gets a verified data graph by name.

# examples

- Get by name:
  <%= config.bin %> <%= command.id %> --target-org my-org --name Customer_Graph
- Return JSON:
  <%= config.bin %> <%= command.id %> --target-org my-org --name Customer_Graph --json

# flags.name.summary

Data graph name.
