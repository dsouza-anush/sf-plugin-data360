# summary

List Data 360 semantic models.

# description

List semantic models from the live-verified semantic model collection.

# examples

- List semantic models:
  <%= config.bin %> <%= command.id %> --target-org my-org
- Return all semantic models as JSON:
  <%= config.bin %> <%= command.id %> --target-org my-org --all --json

# flags.all.summary

Fetch all available semantic models.

# flags.limit.summary

Maximum number of semantic models to return.

# flags.result-format.summary

Format semantic model rows as human, CSV, or JSON output.
