# summary

Describe profile metadata.

# description

Reads all profile metadata or one model.

# examples

- List profile metadata:
  <%= config.bin %> <%= command.id %> --target-org my-org
- Describe one model:
  <%= config.bin %> <%= command.id %> --target-org my-org --name Individual__dlm --json
