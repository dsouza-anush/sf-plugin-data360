# summary

List Document AI configurations.

# description

List Document AI configurations from the live-verified configuration collection.

# examples

- List Document AI configurations:
  <%= config.bin %> <%= command.id %> --target-org my-org
- Return all Document AI configurations as JSON:
  <%= config.bin %> <%= command.id %> --target-org my-org --all --json

# flags.all.summary

Fetch all available Document AI configurations.

# flags.limit.summary

Maximum number of Document AI configurations to return.

# flags.result-format.summary

Format Document AI configuration rows as human, CSV, or JSON output.
