# Query REPL manual checklist

The canonical, packaged operator checklist is [`docs/REPL_CHECKLIST.md`](../../docs/REPL_CHECKLIST.md). It separates non-query TTY checks from one explicitly approved, bounded Query SQL submission so a manual run cannot silently multiply billable work.

Store completed checklists and execution evidence only in the approved restricted evidence location. Do not commit operator, org, approval, result, or environment details to this repository.
